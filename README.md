# Baryo Music

The public website and direct-install APK release page for Baryo Music, an offline-first Android music player for a personal on-device library.

## Pages

- Persian landing page: `/`
- English landing page: `/en/`
- Connected GitHub profile: [BARYOPRO](https://github.com/BARYOPRO)
- APK downloads: [Baryo Music 1.0 release](https://github.com/BARYOPRO/BaryoMusic/releases/tag/v1.0)

The GitHub Pages source is in `docs/`. It contains static HTML/CSS, public branding and app-preview images, and website route metadata. It intentionally does **not** contain the Android app's Kotlin/Gradle source, source ZIP, original app-source repository, or build credentials. The five installable APKs are published as release assets, not committed into the source tree.

## Android install choices

The v1.0 release provides four ABI-specific builds (`arm64-v8a`, `armeabi-v7a`, `x86_64`, and `x86`) plus one universal APK. `arm64-v8a` is recommended for most newer Android phones; use Universal if the device architecture is unknown.

**Signing notice:** these APKs are signed with Android's Debug certificate for direct installation. This is not a Google Play production signing key. In-place upgrades require the same signing key.
