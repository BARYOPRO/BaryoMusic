# Baryo Music 1.6.9 — Restored Stable Audio Behavior

This release removes the later LUFS loudness normalization and Target LUFS controls. ClearSound now uses fixed conservative peak protection only, so moving to the next track or seeking does not change overall loudness.

Six APK-only assets are available for arm64-v8a, armeabi-v7a, x86_64, x86, riscv64 and Universal. No Android source code or keystores are published.
