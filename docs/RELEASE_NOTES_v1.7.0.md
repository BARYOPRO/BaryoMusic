# Baryo Music 1.7.0 — LUFS ClearSound

ClearSound now uses K-weighted short-term loudness control with a 400 ms window, adjustable -18 to -8 LUFS target, gradual gain movement and true-peak safety. The recommended everyday target is -14 LUFS.

Settings categories are numbered and icon-based, with a single-open accordion layout. The Player > ClearSound panel contains the mode selector and LUFS target slider.

Six signed APKs are available for arm64-v8a, armeabi-v7a, x86_64, x86, riscv64 and Universal. No Android source code or keystores are published.
