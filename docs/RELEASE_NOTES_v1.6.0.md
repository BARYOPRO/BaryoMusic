# Baryo Music 1.6.0 — ClearSound & Settings Refresh

Baryo Music 1.6.0 adds ClearSound with Natural, Balanced and Night modes, a sixth Home carousel slide, and a cleaner single-open accordion Settings layout.

ClearSound provides conservative PCM peak protection for smoother listening without pretending to remaster the original recording. Settings are now grouped into Appearance, Library, Player, Storage and About. The Player group includes an expandable ClearSound section alongside existing audio and playback controls.

The release provides six signed APK assets: `arm64-v8a`, `armeabi-v7a`, `x86_64`, `x86`, `riscv64`, and Universal. The visible app version is `1.6.0` (`versionCode` 38). No Android source code or keystores are published.
